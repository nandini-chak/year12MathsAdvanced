1 · Exercise 7D

Find Q as a function of t if: dQ dt = 3, and Q = −1 when t = 0, a dQ dt = 1 −2t, and Q = 2 when t = 0, b dQ dt = cos t, and Q = 1 when t = 0, c dQ dt = et, and Q = 0 when t = 0. d

Formula: If a rate is \dfrac{dQ}{dt}=f(t), then total change Q=\int f(t)\,dt over the interval.

a dQ dt = 3, then Q = ∫ 3 dt = 3t + C If Q = −1 when t = 0, then 3 × 0 + C = −1 and C = −1.

Therefore, Q = 3t −1.

b dQ dt = 1 −2t, then Q = ∫ (1 −2t) dt = t −t2 + C If Q = 2 when t = 0, then 0 −02 + C = 2 and C = 2.

Therefore, Q = 2 + t −t2.

c dQ dt = cos t, then Q = ∫ cos t dt = sin t + C If Q = 1 when t = 0, then sin 0 + C = 1 and C = 1.

Therefore, Q = sin t + 1.

d dQ dt = et, then Q = ∫ et dt = et + C If Q = 0 when t = 0, then e0 + C = 0 and C = −1.

Therefore, Q = et −1.
