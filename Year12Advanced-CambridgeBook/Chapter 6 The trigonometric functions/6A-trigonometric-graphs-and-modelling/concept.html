What this section is about

We take the familiar waves y=\sin x, y=\cos x and y=\tan x and transform them — stretch, compress, shift left/right, shift up/down — then use those graphs to model springs, tides and temperature.

y=A\sin\big(n(x-b)\big)+c
  • A controls height (amplitude for sine/cosine).
  • n controls how fast the wave repeats (period).
  • b shifts the graph horizontally.
  • c shifts the mean position vertically.

Full detail, worked examples and sketches live in the Tutorial · theory page — this page only sets the scene.

Prior knowledge — quick recap

Check these before the tutorial. If any feel rusty, spend a minute on them first.

1. Radians and the unit circle

Angles in this chapter are in radians. One full turn is 2\pi. Useful landmarks:

0,\quad \dfrac{\pi}{2},\quad \pi,\quad \dfrac{3\pi}{2},\quad 2\pi

2. Parent graphs

  • \sin x and \cos x: period 2\pi, range [-1,1], amplitude 1.
  • \tan x: period \pi, vertical asymptotes at x=\pi/2+k\pi.
y = sin xy = cos x

3. Function transformations (language)

Same words you used for other graphs:

  • y=f(x-b) — shift right if b>0 (plus inside brackets is a common trap: left).
  • y=f(x)+c — shift up if c>0.
  • y=Af(x) — vertical stretch by |A| (reflection if A<0).
  • y=f(nx) — horizontal dilation by 1/|n|.

4. What “modelling” will mean

A context (spring, tide, temperature) is described by the same letters: amplitude = distance from mean to crest; period = time for one cycle; mean = centre line. The tutorial and Exercise 6A put numbers on these.
