9A · The language of probability distributions

Direct path: Concept → Tutorial → Exercise → next section. No extra hubs.

What this section is about

A discrete random variable needs a clear list of values and probabilities.

  • Must: each P(x)\ge 0 and all probabilities sum to 1.
  • Table / graph: show P(X=x) for each possible x.
  • Events: add the probabilities of the values you want.
  • Language: random variable = numerical outcome of a chance experiment.

Full detail and examples live in the Tutorial · theory — this page only sets the scene.
