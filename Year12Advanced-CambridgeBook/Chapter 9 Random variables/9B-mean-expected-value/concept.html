9B · Mean or expected value

Direct path: Concept → Tutorial → Exercise → next section. No extra hubs.

What this section is about

The mean (expected value) is a long-run average of the random variable.

  • Formula: E(X)=\sum x\,P(x) (discrete).
  • Picture it: weight each value by how likely it is.
  • Properties: E(aX+b)=aE(X)+b.
  • We practise: build the table, then compute the mean carefully.

Full detail and examples live in the Tutorial · theory — this page only sets the scene.
