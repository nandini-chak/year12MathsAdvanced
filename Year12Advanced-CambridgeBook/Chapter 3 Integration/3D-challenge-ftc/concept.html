Then the definite integral is clearly represented as a function of its upper limit x, as in the first diagram above. For the purposes of this proof, this function is called the signed area function for f(x) starting at x = a: A(x) = ∫x a f(t) dt x A x  a The function A(x) is clearly zero at x = a. For the function sketched above, A(x) is always increasing to the right of x = a, as in the second sketch. To the left of x = a, A(x) is also defined, with the integrals running backwards, so it is always negative and decreasing. And there is an inflection at x = a because f(t) has a minimum. The signed area function The function in the sketch above was never negative. But the definite integral is the signed area under the curve, meaning that a negative sign is attached to areas of regions below the x-axis (provided that the integral is not running backwards). The upper graph of f(t) to the right is a parabola with axis of symmetry x = b. The four areas marked B are all equal. Here are some properties of the signed area function: A(x) = ∫x a f(t) dt. • A(a) = 0, as always. • In the interval (a, c), f(t) is negative, so A(x) is decreasing. • A(x) has an inflection at x = b, where f(t) has a minimum. • In the interval (c, ∞), f(t) is positive, so A(x) is increasing. • A(b) = −B and A(c) = −2B and A(d) = −B. • A(x) is also defined in the interval (−∞, a) to the left of a, where it is negative because the integrals run backwards and the curve is above the x-axis. x A x  t f t( ) a b c d a b c d B B B B The lower diagram above is a sketch of the signed area function A(x) of f(x).
