The definite integral as a function of its upper limit The value of a definite integral ∫b a f(x) dx changes when the value of b changes. This means that it is a function of its upper limit b. When we want to emphasise the functional relationship with the upper limit, we usually replace the letter b by the letter x, the conventional variable of a function. t x y a In turn, the original letter x needs to be replaced by some other letter, usually t.
