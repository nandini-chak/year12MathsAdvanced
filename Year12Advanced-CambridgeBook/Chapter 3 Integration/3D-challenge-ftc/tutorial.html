The definite integral as a function of its upper limit The value of a definite integral ∫b a f(x) dx changes when the value of b changes. This means that it is a function of its upper limit b. When we want to emphasise the functional relationship with the upper limit, we usually replace the letter b by the letter x, the conventional variable of a function. t x y a In turn, the original letter x needs to be replaced by some other letter, usually t. Then the definite integral is clearly represented as a function of its upper limit x, as in the first diagram above. For the purposes of this proof, this function is called the signed area function for f(x) starting at x = a: A(x) = ∫x a f(t) dt x A x  a The function A(x) is clearly zero at x = a. For the function sketched above, A(x) is always increasing to the right of x = a, as in the second sketch. To the left of x = a, A(x) is also defined, with the integrals running backwards, so it is always negative and decreasing. And there is an inflection at x = a because f(t) has a minimum. The signed area function The function in the sketch above was never negative. But the definite integral is the signed area under the curve, meaning that a negative sign is attached to areas of regions below the x-axis (provided that the integral is not running backwards). The upper graph of f(t) to the right is a parabola with axis of symmetry x = b. The four areas marked B are all equal. Here are some properties of the signed area function: A(x) = ∫x a f(t) dt. • A(a) = 0, as always. • In the interval (a, c), f(t) is negative, so A(x) is decreasing. • A(x) has an inflection at x = b, where f(t) has a minimum. • In the interval (c, ∞), f(t) is positive, so A(x) is increasing. • A(b) = −B and A(c) = −2B and A(d) = −B. • A(x) is also defined in the interval (−∞, a) to the left of a, where it is negative because the integrals run backwards and the curve is above the x-axis. x A x  t f t( ) a b c d a b c d B B B B The lower diagram above is a sketch of the signed area function A(x) of f(x).

Theorem. If f(x) is continuous in a suitable closed interval, then the signed area function for f(x) is a primitive of f(x). That is: A′(x) = d dx ∫x a f(t) dt = f(x) . Proof Because the theorem is so fundamental, its proof must begin with the definition of the derivative as a limit: A′(x) = lim h→0 A(x + h) −A(x) h . Subtracting areas in the diagram to the right: A(x + h) −A(x) = ∫x+h x f(t) dt, so A′(x) = limh→0 1 h ∫x+h x f(t) dt. t y a x x h + This limit is handled by means of a clever sandwiching technique.

Theorem. Suppose that f(x) is continuous in the closed interval [a, b], and that F(x) is any primitive of f(x). Then: ∫b a f(x) dx = F(b) −F(a) . Proof We now know that F(x) and ∫x a f(t) dt are both primitives of f(x). Because any two primitives differ only by a constant: ∫x a f(t) dt = F(x) + C, for some constant C. Substituting x = a, ∫a a f(t) dt = F(a) + C.
