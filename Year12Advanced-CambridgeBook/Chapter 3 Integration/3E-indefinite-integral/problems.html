14 · Exercise 3E

Explain why the indefinite integral ∫1 x dx cannot be found in the usual way using the standard form ∫ xn dx = xn+1 n + 1 + C.

The indefinite integral ∫1 x dx = ∫ x−1 dx If applying the standard form shown, it would equal x0 0 + C which is undefined. Dividing by zero is an invalid operation. Therefore, the standard form does not apply to this particular integral.
