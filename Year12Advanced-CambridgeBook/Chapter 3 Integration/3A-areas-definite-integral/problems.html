[An investigation using technology] Some of the previous questions involve summing the areas of lower and upper rectangles or trapezia to approximate a definite integral. Many software programs can do this automatically, using any prescribed number of rectangles or trapezia. Steadily increasing the number of rectangles or trapezia will show the sums of their areas converging to the exact area, which can be checked either using area formulae or using the exact value of the definite integral as calculated later in the course.
