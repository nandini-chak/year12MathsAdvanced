3F · Finding areas by integration

Direct path: Concept → Tutorial → Exercise → next section. No extra hubs.

What this section is about

Use definite integrals to find areas between curves and axes.

  • Above axis: area = integral.
  • Below axis: area = absolute value of the integral (take positive size).
  • Between curves: integrate (upper − lower).
  • Sketch first: mark intersections so the limits are right.
