1A · Sequences and how to specify them

Direct path: Concept → Tutorial → Exercise → next section. No extra hubs.

What this section is about

A sequence is an ordered list with a clear first term, then a next, then a next — like walkers in single file.

  • Picture it: each term has a place — 1st, 2nd, 3rd, … (points on a line do not count: no “next” point).
  • Finite: stops — e.g. 1,3,5,\ldots,99 (fifty odd numbers < 100).
  • Infinite: never stops — e.g. 1,3,5,7,\ldots (all odd whole numbers).
  • Repeats OK: e.g. 1,0,-1,0,1,\ldots from sine of multiples of 90^\circ.
  • This chapter: number sequences only. We write a_n for the nth term.
  • How we specify them: list some terms · formula for a_n · recursive rule (next from previous).

Full detail and examples live in the Tutorial · theory — this page only sets the scene.

Prior knowledge — quick notes

Keep these in mind. For full teaching detail, open the Tutorial (or the earlier section where you first met the idea).

  • A sequence has a first term a_1, then a_2,a_3,\ldots.
  • Finite = last term; infinite = continues forever.
  • Specify by listing, formula for a_n, or recursive rule.
