Problems with worked solutions

Attempt on paper first. Each part has its own solution button. Open one part at a time.

How to read the symbol a_n. It means “the nth term”. The n is a subscript — it sits lower than the a. It is not the two letters “an” written side by side. a_1 is the first term, a_2 is the second term, and so on.

1 · Exercise 1A Foundation

Alex collects stamps. He found 700 stamps in the attic. Every month after that he buys 150 more stamps. The numbers of stamps at the end of each month form the sequence 850, 1000, \ldots

(a) Copy the sequence and continue it for at least 12 terms, then write dots \ldots

(b) After how many months did the collection first go over 2000 stamps?

Quick fact: If the same number is added every time, the next term = previous term + that number.

Step 1 · The jump from 850 to 1000 is 1000-850=150. He adds 150 stamps each month, so keep adding 150.

a_1=850

a_2=850+150=1000

a_3=1000+150=1150

a_4=1150+150=1300

a_5=1300+150=1450

a_6=1450+150=1600

a_7=1600+150=1750

a_8=1750+150=1900

a_9=1900+150=2050

a_{10}=2050+150=2200

a_{11}=2200+150=2350

a_{12}=2350+150=2500

850, 1000, 1150, 1300, 1450, 1600, 1750, 1900, 2050, 2200, 2350, 2500, \ldots

Step 1 · Use the list from part (a). We want the first term that is bigger than 2000.

a_8=1900, and 1900 is still under 2000.

a_9=2050, and 2050 is over 2000.

The collection first went over 2000 stamps after 9 months.

2 · Exercise 1A

Write down the next four terms of each sequence. Each part is a separate list.

(a) 5, 10, 15, \ldots

(b) 6, 16, 26, \ldots

(c) 2, 4, 8, \ldots

(d) 3, 6, 12, \ldots

(e) 38, 34, 30, \ldots

(f) 39, 30, 21, \ldots

(g) 24, 12, 6, \ldots

(h) 81, 27, 9, \ldots

(i) -1, 1, -1, \ldots

(j) 1, 4, 9, \ldots

(k) \tfrac{1}{2}, \tfrac{2}{3}, \tfrac{3}{4}, \ldots

(l) 16, -8, 4, \ldots

Quick fact: Find the rule from one term to the next, then use that same rule four more times. Write each new term on its own line.

Rule · 10-5=5 and 15-10=5. Add 5 each time.

15+5=20

20+5=25

25+5=30

30+5=35

Next four terms: 20, 25, 30, 35.

Same method · 16-6=10 and 26-16=10. Add 10 each time.

26+10=36

36+10=46

46+10=56

56+10=66

Next four terms: 36, 46, 56, 66.

Same method · 4=2\times 2 and 8=4\times 2. Double each time (multiply by 2).

8\times 2=16

16\times 2=32

32\times 2=64

64\times 2=128

Next four terms: 16, 32, 64, 128.

Same method · 6=3\times 2 and 12=6\times 2. Double each time.

12\times 2=24

24\times 2=48

48\times 2=96

96\times 2=192

Next four terms: 24, 48, 96, 192.

Same method · 34-38=-4 and 30-34=-4. Subtract 4 each time.

30-4=26

26-4=22

22-4=18

18-4=14

Next four terms: 26, 22, 18, 14.

Same method · 30-39=-9 and 21-30=-9. Subtract 9 each time.

21-9=12

12-9=3

3-9=-6

-6-9=-15

Next four terms: 12, 3, −6, −15.

Same method · 12=24\div 2 and 6=12\div 2. Halve each time (divide by 2).

6\div 2=3

3\div 2=\tfrac{3}{2}

\tfrac{3}{2}\div 2=\tfrac{3}{4}

\tfrac{3}{4}\div 2=\tfrac{3}{8}

Next four terms: 3, \tfrac{3}{2}, \tfrac{3}{4}, \tfrac{3}{8}.

Same method · 27=81\div 3 and 9=27\div 3. Divide by 3 each time.

9\div 3=3

3\div 3=1

1\div 3=\tfrac{1}{3}

\tfrac{1}{3}\div 3=\tfrac{1}{9}

Next four terms: 3, 1, \tfrac{1}{3}, \tfrac{1}{9}.

Same method · 1=(-1)\times(-1) and -1=1\times(-1). Multiply by −1 each time. The sign flips.

-1\times(-1)=1

1\times(-1)=-1

-1\times(-1)=1

1\times(-1)=-1

Next four terms: 1, −1, 1, −1.

Same method · 1=1^2, 4=2^2, 9=3^2. These are the square numbers. The next squares use 4, 5, 6 and 7.

4^2=4\times 4=16

5^2=5\times 5=25

6^2=6\times 6=36

7^2=7\times 7=49

Next four terms: 16, 25, 36, 49.

Quick fact: The nth term is a_n=\dfrac{n}{n+1}. The top number goes up by 1, and the bottom number is always one more than the top.

The three given terms are term 1, term 2 and term 3. The next four are terms 4 to 7.

a_4=\dfrac{4}{5}

a_5=\dfrac{5}{6}

a_6=\dfrac{6}{7}

a_7=\dfrac{7}{8}

Next four terms: \tfrac{4}{5}, \tfrac{5}{6}, \tfrac{6}{7}, \tfrac{7}{8}.

Same method · -8=16\div(-2) and 4=(-8)\div(-2). Divide by −2 each time.

4\div(-2)=-2

-2\div(-2)=1

1\div(-2)=-\tfrac{1}{2}

\left(-\tfrac{1}{2}\right)\div(-2)=\tfrac{1}{4}

Next four terms: -2, 1, -\tfrac{1}{2}, \tfrac{1}{4}.

3 · Exercise 1A

Find the first four terms of each sequence. Put n=1, then n=2, then n=3, then n=4 into the formula for a_n.

(a) a_n=6n

(b) a_n=5n-2

(c) a_n=2^n

(d) a_n=5^n

(e) a_n=20-n

(f) a_n=6-2n

(g) a_n=3\times 2^n

(h) a_n=7\times 10^n

(i) a_n=n^3

(j) a_n=n(n+1)

(k) a_n=(-1)^n

(l) a_n=(-3)^n

Quick fact: a_n is the nth term. Replace the letter n with 1, then 2, then 3, then 4. Do not change the 6.

a_1=6\times 1=6

a_2=6\times 2=12

a_3=6\times 3=18

a_4=6\times 4=24

First four terms: 6, 12, 18, 24.

Same method · In a_n=5n-2, work out 5n first, then subtract 2.

a_1=5\times 1-2=5-2=3

a_2=5\times 2-2=10-2=8

a_3=5\times 3-2=15-2=13

a_4=5\times 4-2=20-2=18

First four terms: 3, 8, 13, 18.

Quick fact: 2^n means 2 multiplied by itself n times. The small n up high is a power, not a subscript. 2^1=2, 2^2=2\times 2, 2^3=2\times 2\times 2.

a_1=2^1=2

a_2=2^2=2\times 2=4

a_3=2^3=2\times 2\times 2=8

a_4=2^4=2\times 2\times 2\times 2=16

First four terms: 2, 4, 8, 16.

Same method · 5^n means 5 multiplied by itself n times.

a_1=5^1=5

a_2=5^2=5\times 5=25

a_3=5^3=5\times 5\times 5=125

a_4=5^4=125\times 5=625

First four terms: 5, 25, 125, 625.

Same method · In a_n=20-n, start at 20 and subtract n.

a_1=20-1=19

a_2=20-2=18

a_3=20-3=17

a_4=20-4=16

First four terms: 19, 18, 17, 16.

Same method · In a_n=6-2n, work out 2n first, then subtract it from 6.

a_1=6-2\times 1=6-2=4

a_2=6-2\times 2=6-4=2

a_3=6-2\times 3=6-6=0

a_4=6-2\times 4=6-8=-2

First four terms: 4, 2, 0, −2.

Quick fact: In 3\times 2^n the power is only on the 2. Work out 2^n first, then multiply by 3.

a_1=3\times 2^1=3\times 2=6

a_2=3\times 2^2=3\times 4=12

a_3=3\times 2^3=3\times 8=24

a_4=3\times 2^4=3\times 16=48

First four terms: 6, 12, 24, 48.

Same method · In 7\times 10^n, work out the power of 10 first, then multiply by 7. 10^1=10, 10^2=100, 10^3=1000, 10^4=10000.

a_1=7\times 10=70

a_2=7\times 100=700

a_3=7\times 1000=7000

a_4=7\times 10000=70000

First four terms: 70, 700, 7000, 70 000.

Same method · n^3 means n\times n\times n.

a_1=1^3=1\times 1\times 1=1

a_2=2^3=2\times 2\times 2=8

a_3=3^3=3\times 3\times 3=27

a_4=4^3=4\times 4\times 4=64

First four terms: 1, 8, 27, 64.

Same method · a_n=n(n+1) means “the term number, times one more than the term number”.

a_1=1\times(1+1)=1\times 2=2

a_2=2\times(2+1)=2\times 3=6

a_3=3\times(3+1)=3\times 4=12

a_4=4\times(4+1)=4\times 5=20

First four terms: 2, 6, 12, 20.

Quick fact: (-1)^n flips sign. An odd power is −1. An even power is (-1)\times(-1)=+1.

a_1=(-1)^1=-1

a_2=(-1)^2=(-1)\times(-1)=1

a_3=(-1)^3=1\times(-1)=-1

a_4=(-1)^4=(-1)\times(-1)=1

First four terms: −1, 1, −1, 1.

Same method · (-3)^n means −3 multiplied by itself n times. A negative times a negative is positive, so even powers are positive and odd powers are negative.

a_1=(-3)^1=-3

a_2=(-3)^2=(-3)\times(-3)=9

a_3=(-3)^3=9\times(-3)=-27

a_4=(-3)^4=(-27)\times(-3)=81

First four terms: −3, 9, −27, 81.

8 · Exercise 1A

The nth term is a_n=3n+1.

(a) Put a_n=40, and show that 40 is the 13th term.

(b) Put a_n=30, and show that 30 is not a term.

(c) In the same way, decide whether 100, 200 and 1000 are terms.

Quick fact: Set a_n equal to the number you are testing, and solve for n. The number is a term only if n is a whole number.

a_n=3n+1

Put a_n=40: 40=3n+1

Subtract 1 from both sides: 39=3n

Divide by 3: n=39\div 3=13

13 is a whole number. Check: 3\times 13+1=39+1=40.

Yes. 40 is the 13th term.

Same method · a_n=3n+1. Put a_n=30.

30=3n+1

Subtract 1: 29=3n

Divide by 3: n=29\div 3=9\tfrac{2}{3} (about 9.666…)

9\tfrac{2}{3} is not a whole number, so there is no term number that gives 30.

30 is not a term of the sequence.

Same formula · a_n=3n+1. Test each number on its own.

100 · 100=3n+1, so 99=3n, so n=99\div 3=33. 33 is a whole number, so 100 is the 33rd term. Check: 3\times 33+1=100.

200 · 200=3n+1, so 199=3n, so n=199\div 3=66\tfrac{1}{3}. Not a whole number, so 200 is not a term.

1000 · 1000=3n+1, so 999=3n, so n=999\div 3=333. 333 is a whole number, so 1000 is the 333rd term. Check: 3\times 333+1=1000.

100 is a term. 200 is not a term. 1000 is a term.
