Theory · key ideas

An AP adds the same number each step — that number is the common difference d.

  • Test: check a_2-a_1, a_3-a_2, … are all equal to d.
  • Recursive: a_n=a_{n-1}+d.
  • nth term: a_n=a+(n-1)d.
  • Link: like a straight-line function sampled at n=1,2,3,\ldots.
a_n=a+(n-1)d

More practice lives on the Exercise page. This tutorial stays short on purpose (Very Poor knowledge level).

Worked mini-examples

Example · is it an AP?

Step 1 · 46,43,40,37: differences -3,-3,-3 → AP with a=46, d=-3.

Step 2 · 1,4,9,16: differences 3,5,7 → not an AP.

Example · 20th term

Step 1 · a=2, d=5 → a_{20}=2+19\times 5=97.

Step 2 · Same method: a=10, d=-3 → a_{20}=10+19(-3)=-47.

Example · how many terms?

Step 1 · Sequence 26,35,44,\ldots,917: a=26, d=9 so a_n=17+9n.

Step 2 · Set 17+9n=917 → n=100 terms.
