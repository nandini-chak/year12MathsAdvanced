1B · Arithmetic sequences

What this section is about

An arithmetic sequence (AP) adds the same number each time.

  • Picture it: 3,13,23,33,\ldots — each term is 10 more than the one before.
  • Common difference d: a_n-a_{n-1}=d (always the same).
  • nth term: start at a, add d again and again → a_n=a+(n-1)d.
  • Link: plotting term number vs value looks like a straight line.
  • We practise: finding a, d, or a_n, and word problems.

Full detail and examples live in the Tutorial · theory — this page only sets the scene.
