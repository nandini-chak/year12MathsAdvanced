240 Chapter 5 Logarithmic functions 5E 5E Applications of integration Learning intentions • Use integration to find areas associated with hyperbolic graphs. The usual applications of integration can now be applied to the reciprocal function, whose primitive was previously unavailable. Finding areas by integration The next worked example involves sketching a hyperbolic curve and finding an area associated with it. Example 21 Find an area associated with a hyperbolic curve a Find the x-intercept and y-intercept of y = 12 x + 3 −2 . b Sketch the curve for x > −3 using transformations of y = 1 x, and write down its asymptotes. c Shade the region contained between the curve and the x-axis, and between the y-axis and the line x = 6. d Find the shaded area, in exact form, and then correct to four decimal places. Solution a When x = 0, y = 2, and when y = 0, x = 3. b Shift y = 1 x left 3, then dilate vertically with factor 12, then shift down 2. Now x = −3 is a vertical asymptote, and y = −2 is a horizontal asymptote. c The asymptote is x = −3, so the areas are all to the right of the asymptote, and there is no need for absolute value signs.      x y ∫3 0 12 x + 3 −2 ! dx = 12 loge(x + 3) −2x3 0 = (12 loge 6 −6) −(12 loge 3 −0) = 12 loge 3 + 12 loge 2 −6 −12 loge 3 = 12 loge 2 −6, which is positive, as expected. ∫6 3 12 x + 3 −2 ! dx = 12 loge(x + 3) −2x6 3 = (12 loge 9 −12) −(12 loge 6 −6) = 24 loge 3 −12 −12 loge 3 −12 loge 2 + 6 = 12 loge 3 −12 loge 2 −6, which is negative, as expected. Hence total area = (12 loge 2 −6) −(12 loge 3 −12 loge 2 −6) = 24 loge 2 −12 loge 3 (or 12 loge 4 3) ≑3.4522.
