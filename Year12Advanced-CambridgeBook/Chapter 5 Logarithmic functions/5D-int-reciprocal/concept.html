What this section is about

• Develop standard forms for the integration of y = 1 x. • Understand why the integral of 1 x is loge |x|. • Develop a standard form for the reverse chain rule. • Reverse a given differentiation to find an integral. The reciprocal function y = 1 x is an important function — we have seen that it is needed whenever two quantities are inversely proportional. Its graph is a hyperbola, and hyperbolic graphs therefore occur widely throughout applications. So far, however, it has not been possible to integrate the reciprocal function, because the usual rule for integrating powers of x gives nonsense: When n = −1, the standard form ∫ xn dx = xn+1 n + 1 gives ∫ x−1 dx = x0 0 , which is nonsense because of the division by zero. Yet the graph of y = 1 x to the right shows that there should be no problem with definite integrals involving 1 x, provided that the integral keeps aways from the discontinuity at x = 0. For example, the diagram shows the integral ∫2 1 1 x dx, which the little rectangles show has a value between 1 2 and 1. 1 2 1 x y = x y 1 2 1 Integration of the reciprocal function Reversing the standard form for differentiating loge x will now give the standard forms for integrating 1 x. We know that d dx loge x = 1 x , and reversing this, ∫1 x dx = loge x + C, for some constant C. This is a new standard form for integrating the reciprocal function. The only qualification is that x > 0, otherwise loge x is undefined, so we have: ∫1 x dx = loge x + C, provided that x > 0. This result is surprising — one would hardly expect the integral of a power function such as 1 x = x−1 to be a log function whose base is a special number e that was specially identified for exponential functions. Mathematics is unified!
