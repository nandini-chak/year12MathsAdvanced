1 · Calculator ln values Foundation

Use the calculator’s ln button to approximate, correct to four significant figures. (Remember: \ln means \log_e.)

a \log_e 10 · b \log_e 0.1 · c \ln 123\,456 · d \ln 0.000\,006 · e \log_e 50 · f \log_e 0.02

Quick fact: On the calculator, ln means \log_e (natural log). log usually means base 10. Four significant figures means four non-zero leading digits of accuracy (e.g. 2.303 has four sig figs).

a · Press \ln then 10. Display ≈ 2.302585\ldots.

Answer a: 2.303 (4 s.f.).

Formula: \log_e\!\left(\dfrac{1}{a}\right)=-\log_e a when a>0.

b · Same method · Notice 0.1=\dfrac{1}{10}, so \log_e 0.1=-\log_e 10.

From (a), \log_e 10\approx 2.303, so \log_e 0.1\approx -2.303.

Calculator check: \ln 0.1\approx -2.302585 → rounds to -2.303.

Answer b: -2.303 (4 s.f.).

Method: Same calculator button. Type the full number carefully (no spaces): 123456.

c · Same method · Enter \ln 123456. Display ≈ 11.72365\ldots.

Answer c: 11.72 (4 s.f.).

Quick fact: A number smaller than 1 gives a negative natural log. 0.000006 can be typed as 6\times 10^{-6}.

d · Same method · Enter \ln 0.000006 (or \ln(6\times 10^{-6})). Display ≈ -12.02375\ldots.

Answer d: -12.02 (4 s.f.).

Method: Calculator \ln button. Optional check with product law: \log_e(ab)=\log_e a+\log_e b.

e · Same method · Enter \ln 50. Display ≈ 3.912023\ldots.

Optional: 50=5\times 10 → \ln 50=\ln 5+\ln 10.

Answer e: 3.912 (4 s.f.).

Formula: \log_e\!\left(\dfrac{1}{a}\right)=-\log_e a.

f · Same method · 0.02=\dfrac{1}{50}, so \log_e 0.02=-\log_e 50\approx -3.912.

Answer f: -3.912 (4 s.f.).

2 · Exact values with identities Foundation

Use the identities \log_e(e^x)=x (all real x) and e^{\log_e x}=x (x>0) to simplify:

a \log_e e^3 · b \log_e e^{-1} · c \log_e\!\left(\dfrac{1}{e^2}\right) · d \log_e\sqrt{e}

e e^{\ln 5} · f e^{\ln 0.05} · g e^{\ln 1} · h e^{\ln e}

Identity: \log_e(e^k)=k. The log and the exponential cancel; leave the power.

a · \log_e(e^3)=3.

Answer a: 3.

Same identity: \log_e(e^k)=k.

b · Same method · k=-1, so \log_e(e^{-1})=-1.

Answer b: -1.

Quick fact: \dfrac{1}{e^2}=e^{-2}, then use \log_e(e^k)=k.

c · Same method · \log_e\!\left(\dfrac{1}{e^2}\right)=\log_e(e^{-2})=-2.

Answer c: -2.

Quick fact: \sqrt{e}=e^{1/2}, then \log_e(e^k)=k.

d · Same method · \log_e\sqrt{e}=\log_e(e^{1/2})=\tfrac12.

Answer d: \tfrac12.

Identity: e^{\log_e x}=x for x>0. The e and the log cancel; leave the inside.

e · e^{\ln 5}=5.

Answer e: 5.

Same identity: e^{\log_e x}=x (x>0).

f · Same method · e^{\ln 0.05}=0.05.

Answer f: 0.05.

Same identity: e^{\log_e x}=x.

g · Same method · e^{\ln 1}=1.

Answer g: 1.

Same identity: e^{\log_e x}=x.

h · Same method · e^{\ln e}=e.

Answer h: e.

3 · Why ln 1 = 0 and ln e = 1 Foundation

a Use a calculator to confirm \log_e 1=0.

b Write 1 as a power of e, then use \log_e(e^x)=x to show \log_e 1=0.

c Use a calculator to confirm \log_e e=1.

d Write e as a power of e, then use the same identity to show \log_e e=1.

a · Calculator: \ln 1 displays 0.

Confirmed: \log_e 1=0.

Identity: \log_e(e^x)=x. Also e^0=1.

b · Write 1=e^0.

Then \log_e 1=\log_e(e^0)=0 by the identity with x=0.

c · Calculator: \ln e displays 1.

Confirmed: \log_e e=1.

Same identity: \log_e(e^x)=x. Also e=e^1.

d · Same method · Write e=e^1.

Then \log_e e=\log_e(e^1)=1.

4 · Convert log ↔ exponential form Foundation

Convert each exponential equation to logarithmic form, and each logarithmic equation to exponential form.

a x=e^6 · b \log_e x=-2 · c x=\ln 24 · d e^x=\tfrac13

Dictionary: x=e^k means the same as \log_e x=k. (Read: “log base e of x equals the power”.)

a · Given x=e^6 (exponential form).

Logarithmic form: \log_e x=6.

Answer a: \log_e x=6.

Same dictionary the other way: \log_e x=k means x=e^k.

b · Same method · Given \log_e x=-2.

Exponential form: x=e^{-2}.

Answer b: x=e^{-2}.

Quick fact: x=\ln 24 means x=\log_e 24, which is the same as e^x=24.

c · Same method · Given x=\ln 24.

Exponential form: e^x=24.

Answer c: e^x=24.

Same dictionary: e^x=a means x=\log_e a.

d · Same method · Given e^x=\tfrac13.

Logarithmic form: x=\log_e\!\left(\tfrac13\right) (or x=-\log_e 3).

Answer d: x=\log_e\!\left(\tfrac13\right).

5 · Change of base Foundation

Use the change-of-base formula to express each logarithm in terms of logs base e. Then approximate correct to four significant figures.

a \log_2 7 · b \log_{10} 25 · c \log_3 0.04

Change-of-base formula: \log_b x=\dfrac{\log_e x}{\log_e b}=\dfrac{\ln x}{\ln b}.

a · Write \log_2 7=\dfrac{\ln 7}{\ln 2}.

Calculator: \ln 7\approx 1.945910, \ln 2\approx 0.693147.

Divide: 1.945910\div 0.693147\approx 2.807354.

Answer a: \dfrac{\ln 7}{\ln 2}\approx 2.807 (4 s.f.).

Same formula: \log_{10} 25=\dfrac{\ln 25}{\ln 10}.

b · Same method · \ln 25\approx 3.218876, \ln 10\approx 2.302585.

Divide: ≈ 1.397940.

Answer b: \dfrac{\ln 25}{\ln 10}\approx 1.398 (4 s.f.).

Same formula: \log_3 0.04=\dfrac{\ln 0.04}{\ln 3}. Expect a negative value because 0.04<1.

c · Same method · \ln 0.04\approx -3.218876, \ln 3\approx 1.098612.

Divide: ≈ -2.930.

Answer c: \dfrac{\ln 0.04}{\ln 3}\approx -2.930 (4 s.f.).

6 · Solve with logarithms Foundation

Use logarithms to solve these equations correct to four significant figures. (Any base is fine — ln or log₁₀.)

a 5^x=20 · b 3^x=137 · c 7^x=0.7 · d 2^x=0.0123

Method: Take log of both sides. Use \log(a^x)=x\log a, then divide. Any log base works.

a · Start with 5^x=20.

Take log: \log(5^x)=\log 20 → x\log 5=\log 20.

Divide: x=\dfrac{\log 20}{\log 5}\approx 1.861.

Answer a: x\approx 1.861 (4 s.f.).

Same method: x=\dfrac{\log(\text{RHS})}{\log(\text{base})}.

b · Same method · 3^x=137 → x=\dfrac{\log 137}{\log 3}\approx 4.478.

Answer b: x\approx 4.478 (4 s.f.).

Same method: Expect a negative x because the right-hand side is less than 1.

c · Same method · 7^x=0.7 → x=\dfrac{\log 0.7}{\log 7}\approx -0.1833.

Answer c: x\approx -0.1833 (4 s.f.).

Same method: RHS < 1 → negative solution.

d · Same method · 2^x=0.0123 → x=\dfrac{\log 0.0123}{\log 2}\approx -6.345.

Answer d: x\approx -6.345 (4 s.f.).

7 · Reflections of ln x Development

Describe and sketch:

a reflection of y=\ln x in the line y=x (gradient 1 at (1,0));

b reflection in the y-axis (horizontal dilation factor -1).

Reflection fact: Reflecting y=e^x in the line y=x swaps coordinates and gives the inverse y=\log_e x. Reflecting in the y-axis replaces x by -x.

a · Reflection in y=x maps y=e^x to y=\log_e x (its inverse). The tangent to e^x at (0,1) has gradient 1, so after reflection the tangent to \log_e x at (1,0) also has gradient 1.

b · Reflection in the y-axis: replace x by -x to get y=\log_e(-x), domain x<0. This is also a horizontal dilation with factor -1.

13 · Mixed exponentials Development

Log laws: \ln(ab)=\ln a+\ln b, \ln(a/b)=\ln a-\ln b, \ln(a^n)=n\ln a. Inverse facts: \ln e^x=x, e^{\ln x}=x (x>0).

a · Let u=e^x. Then u+\tfrac1u=e^2+e^{-2} → x=e or x=e^4 (Cambridge key).

15 · Planet diameters on a log scale Development

Planets are placed by diameter on a logarithmic axis. Comment on spacing and why the Sun is usually omitted.

Log laws: \ln(ab)=\ln a+\ln b, \ln(a/b)=\ln a-\ln b, \ln(a^n)=n\ln a. Inverse facts: \ln e^x=x, e^{\ln x}=x (x>0).

Equal steps on a log axis represent equal ratios of diameter, so small rocky planets cluster and gas giants spread across orders of magnitude. The Sun is excluded because a log scale needs positive arguments and \ln x\to-\infty as x\to 0^+; treating the Sun would dominate or break the scale unless a separate inset or linear panel is used.

19 · Sequence of transforms Challenge

Starting from y=\ln x, describe a sequence of transformations that produces y=2\ln(x+3)-1, and sketch the result.

Reading order: Inside brackets first (horizontal), then vertical stretch, then vertical shift. Domain: argument of ln must be positive.

Step 1 · Shift left 3: y=\ln(x+3). Domain becomes x>-3; asymptote moves to x=-3.

Step 2 · Vertical stretch factor 2: y=2\ln(x+3).

Step 3 · Shift down 1: y=2\ln(x+3)-1.

Sketch tip: Mark the new asymptote x=-3, the intercept where 2\ln(x+3)-1=0 (solve if needed), and that the curve still rises slowly to the right.

20 · Dilation or translation? Challenge

Explain two valid interpretations of y=\ln(2x): as a horizontal dilation of y=\ln x, and as a vertical shift. Relate to \ln(2x)=\ln x+\ln 2.

Log laws: \ln(ab)=\ln a+\ln b, \ln(a/b)=\ln a-\ln b, \ln(a^n)=n\ln a. Inverse facts: \ln e^x=x, e^{\ln x}=x (x>0).

Horizontal dilation: replace x by 2x, so dilation factor \tfrac12 toward the y-axis — the graph meets the axis at the same y-intercept but rises faster for x>0.

Vertical translation: log laws give \ln(2x)=\ln x+\ln 2, so the same graph is y=\ln x shifted up by \ln 2. Both descriptions are correct; they highlight the dual nature of log transforms.
