1 · Calculator ln values Foundation

Use the calculator’s ln button to approximate, correct to four significant figures. (Remember: \ln means \log_e.)

a \log_e 10 · b \log_e 0.1 · c \ln 123\,456 · d \ln 0.000\,006 · e \log_e 50 · f \log_e 0.02

Quick fact: On the calculator, ln means \log_e (natural log). log usually means base 10. Four significant figures means four non-zero leading digits of accuracy (e.g. 2.303 has four sig figs).

a · Press \ln then 10. Display ≈ 2.302585\ldots.

Answer a: 2.303 (4 s.f.).

Formula: \log_e\!\left(\dfrac{1}{a}\right)=-\log_e a when a>0.

b · Same method · Notice 0.1=\dfrac{1}{10}, so \log_e 0.1=-\log_e 10.

From (a), \log_e 10\approx 2.303, so \log_e 0.1\approx -2.303.

Calculator check: \ln 0.1\approx -2.302585 → rounds to -2.303.

Answer b: -2.303 (4 s.f.).

Method: Same calculator button. Type the full number carefully (no spaces): 123456.

c · Same method · Enter \ln 123456. Display ≈ 11.72365\ldots.

Answer c: 11.72 (4 s.f.).

Quick fact: A number smaller than 1 gives a negative natural log. 0.000006 can be typed as 6\times 10^{-6}.

d · Same method · Enter \ln 0.000006 (or \ln(6\times 10^{-6})). Display ≈ -12.02375\ldots.

Answer d: -12.02 (4 s.f.).

Method: Calculator \ln button. Optional check with product law: \log_e(ab)=\log_e a+\log_e b.

e · Same method · Enter \ln 50. Display ≈ 3.912023\ldots.

Optional: 50=5\times 10 → \ln 50=\ln 5+\ln 10.

Answer e: 3.912 (4 s.f.).

Formula: \log_e\!\left(\dfrac{1}{a}\right)=-\log_e a.

f · Same method · 0.02=\dfrac{1}{50}, so \log_e 0.02=-\log_e 50\approx -3.912.

Answer f: -3.912 (4 s.f.).

5 · Change of base Foundation

Use the change-of-base formula to express each logarithm in terms of logs base e. Then approximate correct to four significant figures.

a \log_2 7 · b \log_{10} 25 · c \log_3 0.04

Change-of-base formula: \log_b x=\dfrac{\log_e x}{\log_e b}=\dfrac{\ln x}{\ln b}.

a · Write \log_2 7=\dfrac{\ln 7}{\ln 2}.

Calculator: \ln 7\approx 1.945910, \ln 2\approx 0.693147.

Divide: 1.945910\div 0.693147\approx 2.807354.

Answer a: \dfrac{\ln 7}{\ln 2}\approx 2.807 (4 s.f.).

Same formula: \log_{10} 25=\dfrac{\ln 25}{\ln 10}.

b · Same method · \ln 25\approx 3.218876, \ln 10\approx 2.302585.

Divide: ≈ 1.397940.

Answer b: \dfrac{\ln 25}{\ln 10}\approx 1.398 (4 s.f.).

Same formula: \log_3 0.04=\dfrac{\ln 0.04}{\ln 3}. Expect a negative value because 0.04<1.

c · Same method · \ln 0.04\approx -3.218876, \ln 3\approx 1.098612.

Divide: ≈ -2.930.

Answer c: \dfrac{\ln 0.04}{\ln 3}\approx -2.930 (4 s.f.).

7 · Reflections of ln x Development

Describe and sketch:

a reflection of y=\ln x in the line y=x (gradient 1 at (1,0));

b reflection in the y-axis (horizontal dilation factor -1).

Reflection fact: Reflecting y=e^x in the line y=x swaps coordinates and gives the inverse y=\log_e x. Reflecting in the y-axis replaces x by -x.

a · Reflection in y=x maps y=e^x to y=\log_e x (its inverse). The tangent to e^x at (0,1) has gradient 1, so after reflection the tangent to \log_e x at (1,0) also has gradient 1.

b · Reflection in the y-axis: replace x by -x to get y=\log_e(-x), domain x<0. This is also a horizontal dilation with factor -1.

11 · Exponential quadratics Development

a Use the substitution u=2^x to solve 4^x-9\times 2^x+14=0.

b Use a similar substitution to solve 3^{2x}-8\times 3^x-9=0.

c Solve for x:

i 25^x-26\times 5^x+25=0 · ii 9^x-5\times 3^x+4=0

iii 3^{2x}-3^x-20=0 · iv 4^x-3\times 2^{x+1}+2^3=0

Method: Write every power with the same base. Remember 4^x=(2^2)^x=(2^x)^2. Then put u=2^x (always positive) and solve an ordinary quadratic.

a · Step 1 · Rewrite: 4^x=(2^x)^2, so the equation is (2^x)^2-9\cdot 2^x+14=0.

Step 2 · Let u=2^x. Then u^2-9u+14=0.

Step 3 · Factor: (u-2)(u-7)=0, so u=2 or u=7.

Step 4 · Back-substitute. If 2^x=2, then x=1. If 2^x=7, then x=\log_2 7.

Answer a: x=1 or x=\log_2 7.

Same method: Write 3^{2x}=(3^x)^2, put u=3^x (always positive), solve the quadratic, then reject any negative u.

b · Step 1 · Equation becomes (3^x)^2-8\cdot 3^x-9=0.

Step 2 · Let u=3^x. Then u^2-8u-9=0.

Step 3 · Factor: (u+1)(u-9)=0, so u=-1 or u=9.

Step 4 · 3^x=-1 is impossible (powers of 3 are never negative). 3^x=9=3^2 → x=2.

Answer b: x=2.

Same method: 25^x=(5^2)^x=(5^x)^2. Put u=5^x.

c i · (5^x)^2-26\cdot 5^x+25=0. Let u=5^x: u^2-26u+25=0.

Factor: (u-1)(u-25)=0 → u=1 or u=25.

5^x=1\Rightarrow x=0. 5^x=25=5^2\Rightarrow x=2.

Answer c i: x=0 or x=2.

Same method: 9^x=(3^x)^2. Put u=3^x.

c ii · u^2-5u+4=0 → (u-1)(u-4)=0 → u=1 or u=4.

3^x=1\Rightarrow x=0. 3^x=4\Rightarrow x=\log_3 4.

Answer c ii: x=0 or x=\log_3 4.

Same method: 3^{2x}=(3^x)^2. Put u=3^x. Reject negative u.

c iii · u^2-u-20=0 → (u+4)(u-5)=0 → u=-4 or u=5.

3^x=-4 impossible. 3^x=5\Rightarrow x=\log_3 5.

Answer c iii: x=\log_3 5.

Same method + tidy first: 2^{x+1}=2\cdot 2^x and 2^3=8. Put u=2^x.

c iv · Start with 4^x-3\cdot 2^{x+1}+8=0.

Rewrite: (2^x)^2-3\cdot(2\cdot 2^x)+8=0 → u^2-6u+8=0.

Factor: (u-2)(u-4)=0 → u=2 or u=4.

2^x=2\Rightarrow x=1. 2^x=4=2^2\Rightarrow x=2.

Answer c iv: x=1 or x=2.

Use the substitution u=e^x or u=e^{2x} to reduce each equation to a quadratic and solve. Write answers as logarithms base e, unless they simplify further.

a e^{2x}-2e^x+1=0 · b e^{2x}+e^x-6=0

c e^{4x}-10e^{2x}+9=0 · d e^{4x}-e^{2x}=0

13 · Quadratics in \ln x Development

Use a substitution to solve:

a (\log_e x)^2-5\log_e x+4=0 · b (\log_e x)^2=3\log_e x

Method: Put u=\log_e x. Solve the quadratic for u, then convert with x=e^u. Domain: x>0.

a · Let u=\log_e x. Then u^2-5u+4=0 → (u-1)(u-4)=0 → u=1 or u=4.

\log_e x=1\Rightarrow x=e. \log_e x=4\Rightarrow x=e^4.

Answer a: x=e or x=e^4.

Same method: Put u=\log_e x. Bring all terms to one side before factoring (do not cancel u too early — you would lose a root).

b · u^2=3u → u^2-3u=0 → u(u-3)=0 → u=0 or u=3.

\log_e x=0\Rightarrow x=1. \log_e x=3\Rightarrow x=e^3.

Answer b: x=1 or x=e^3.

14 · Log laws practise Development

a Use the laws for logarithms to simplify:

i \log_e e^e · ii \log_e(\log_e e^e) · iii \log_e\!\big(\log_e(\log_e e^e)\big)

b Express as a single logarithm:

i \ln 5+\ln 4 · ii \ln 30-\log_e 6 · iii \ln 12-\ln 15+\ln 10

Formula: \log_e(e^k)=k for any real k.

a i · Here the power is e itself: \log_e(e^e)=e.

Answer a i: e.

Same formula: First simplify the inside using (a i), then take log again.

a ii · From (a i), inside is e. So \log_e(\log_e e^e)=\log_e e=1.

Answer a ii: 1.

Same method · peel the onion: Use the previous answer as the new inside.

a iii · From (a ii), inside is 1. So \log_e(1)=0.

Answer a iii: 0.

Product law: \ln a+\ln b=\ln(ab) (when a>0, b>0).

b i · \ln 5+\ln 4=\ln(5\times 4)=\ln 20.

Answer b i: \ln 20.

Quotient law: \ln a-\ln b=\ln\!\left(\dfrac{a}{b}\right). Note \ln and \log_e are the same.

b ii · \ln 30-\log_e 6=\ln\!\left(\dfrac{30}{6}\right)=\ln 5.

Answer b ii: \ln 5.

Combine laws: \ln a-\ln b+\ln c=\ln\!\left(\dfrac{a\cdot c}{b}\right).

b iii · \ln 12-\ln 15+\ln 10=\ln\!\left(\dfrac{12\times 10}{15}\right)=\ln\!\left(\dfrac{120}{15}\right)=\ln 8.

Answer b iii: \ln 8.

15 · Planet distances on linear and log scales Development

Distances of the eight planets from the Sun in astronomical units (AU), with 1 AU = Earth–Sun distance:

Mercury 0.39 · Venus 0.72 · Earth 1 · Mars 1.52 · Jupiter 5.2 · Saturn 9.5 · Uranus 19.2 · Neptune 30.1 (Sun at 0).

a Place the Sun and eight planets on a linear number line. Comment.

b i Place the eight planets on a log scale (omit the Sun). ii Label with actual AU distances. iii Comment on the grouping.

c Give a plausible astronomical reason for the grouping.

d Why has the Sun been excluded from the log-scale graph?

Linear scale: Equal gaps mean equal differences (e.g. 5 AU, 10 AU, 15 AU look evenly spaced).

a · On 0 to about 35 AU, Mercury–Mars sit almost on top of each other near 0, while Jupiter–Neptune are spread out across most of the line.

Inner four (Me/Ve/Ea/Ma) cluster near the Sun; outer planets spread out.

Comment: The four rocky planets bunch near the Sun; the gas/ice giants are widely spaced.

Log scale: Equal gaps mean equal ratios. Using \ln of each AU (any base works): Mercury ≈ −0.94, Venus ≈ −0.33, Earth 0, Mars ≈ 0.42, Jupiter ≈ 1.65, Saturn ≈ 2.25, Uranus ≈ 2.95, Neptune ≈ 3.40.

b i–ii · Plot those log values on a number line, but label each point with the original AU (0.39, 0.72, …).

b iii · Planets look much more evenly spaced. There is still a clear gap between the inner group (Mercury–Mars) and the outer group (Jupiter–Neptune).

Answer b: Log scale spreads the inner planets and compresses the outer ones into a clearer two-group picture.

c · The gap between Mars and Jupiter is where the asteroid belt sits. A plausible reason for the two groups is that the inner rocky planets formed differently from the outer gas/ice giants (and that gap marks leftover debris).

Answer c: Asteroid belt / different formation of inner vs outer planets (any sensible astronomy reason is fine).

Domain fact: You cannot take \log of 0 (or a negative). As x\to 0^+, \log x\to-\infty.

d · The Sun is at AU = 0. A log scale would need to stretch to -\infty to include it — impossible on a finite number line.

Answer d: Because \log 0 is undefined (the log heads to -\infty).

16 · Richter scale Challenge

On the Richter scale, each increase of 1 means the quake is 10 times more intense (base-10 log scale).

a By what factor is a magnitude-6.5 quake more intense than a magnitude-4 quake? (Nearest integer.)

b An earthquake measured 6. An aftershock had 25% of that magnitude. What did the aftershock measure? (1 d.p.)

Formula: Intensity ratio = 10^{(\text{difference in Richter readings})}.

a · Difference: 6.5-4=2.5.

Factor: 10^{2.5}=10^2\times 10^{0.5}=100\times\sqrt{10}\approx 100\times 3.162=316.2.

Answer a: about 316 times more intense.

Same idea backwards: If intensity is multiplied by k, the Richter reading changes by \log_{10} k.

b · Aftershock intensity = 25% = 0.25 of the original.

Change in reading: \log_{10}(0.25)\approx -0.6021.

New reading: 6+(-0.6021)=5.3979\approx 5.4 (1 d.p.).

Answer b: 5.4 on the Richter scale.

17 · Decibel (sound) scale Challenge

0 dB = least audible sound. Each +10 dB means 10 times louder (also base-10).

a A sound falls from 45 dB to 38 dB. What percentage of the original loudness remains? (Nearest whole percent.)

b A lawnmower is 80 dB. A concert peak is 500 times louder. How many decibels was that peak? (Nearest dB.)

Formula: Loudness ratio = 10^{(\Delta\text{dB})/10}. (Because +10 dB = ×10, so divide the dB change by 10 before raising 10 to that power.)

a · Drop: 38-45=-7 dB.

Ratio of loudness: 10^{-7/10}=10^{-0.7}\approx 0.1995.

As a percentage: about 20\% of the original loudness remains.

Answer a: about 20%.

Formula: Extra dB = 10\log_{10}(\text{factor}). Then add to the starting dB.

b · Factor = 500. Extra dB: 10\log_{10} 500=10\times\log_{10}(5\times 10^2)=10(2+\log_{10}5)\approx 10(2+0.6990)=26.99.

Peak: 80+26.99\approx 107 dB.

Answer b: 107 dB.

20 · Dilation or translation? Challenge

a Interpret the change from y=\log_e x to y=\log_e(5x) as a dilation, then as a translation.

b Interpret the change from y=\log_e x to y=\log_e x+2 as a translation, then as a dilation (hint: write 2 as \log_e e^2).

Two readings of the same graph: Product law \log_e(5x)=\log_e x+\log_e 5 links a horizontal dilation to a vertical shift.

a · As a dilation: Replace x by 5x → horizontal stretch with factor \tfrac15.

As a translation: \log_e(5x)=\log_e x+\log_e 5, so shift y=\log_e x up by \log_e 5.

Answer a: Horizontal dilation factor 1/5, or vertical shift up by \log_e 5.

Same idea the other way: 2=\log_e(e^2), so \log_e x+2=\log_e x+\log_e(e^2)=\log_e(e^2 x).

b · As a translation: Shift y=\log_e x up by 2.
