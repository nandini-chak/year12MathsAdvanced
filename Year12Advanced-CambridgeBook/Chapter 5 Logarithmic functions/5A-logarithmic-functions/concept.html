What this section is about

The equation y=\log_e x means “x=e^y”. It is the inverse of y=e^x. We graph it, transform it like any other function, and use it to solve equations — including ones that become quadratics after a substitution.

\log_e(e^x)=x,\qquad e^{\log_e x}=x\quad (x>0)

Key features of the parent graph: domain (0,\infty), vertical asymptote x=0, intercept (1,0), gradient 1 at that point, concave down. The same function is written \ln x.

Prior knowledge — quick recap

Check these before the tutorial.

1. Exponential base e

y=e^x is always positive, passes through (0,1), and increases rapidly. Its inverse swaps the roles of x and y.

2. Parent logarithm

  • Domain: x>0 only.
  • Range: all real y.
  • Asymptote: x=0 (the y-axis).
y = ln xy = e^x (inverse)

3. Transformation language

  • y=\log_e(-x) — reflection in the y-axis.
  • y=\log_e x + c — vertical shift.
  • y=\log_e(x-b) — horizontal shift (watch the domain).
  • y=A\log_e x — vertical stretch; y=\log_e(kx) often looks like a vertical shift because \log_e(kx)=\log_e x+\log_e k.
T Teacher note
Keep this page short. The “horizontal dilation = vertical translation” idea is developed fully in the tutorial — flag it here only as a hook.

4. Index laws and quadratics

Many equations use u=e^x or u=\log_e x so a quadratic in u appears. You also need change of base: \log_b x=\dfrac{\log_e x}{\log_e b}.
