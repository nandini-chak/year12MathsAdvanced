What this section is about

y=e^x is the unique exponential that is its own derivative: at every point, gradient equals height. We review the parent graph, common transformations (including when a vertical stretch is the same as a horizontal shift), and tangents/normals to curves like y=ke^x.

\dfrac{d}{dx}e^x=e^x,\qquad e\approx 2.7183

Full theory, Examples 1–3 and a graph studio live in the Tutorial · theory page.

Prior knowledge — quick recap

Check these before the tutorial.

1. Parent graph y=e^x

  • Domain all real x; range y>0.
  • Passes through (0,1); horizontal asymptote y=0 on the left.
  • Always increasing and always concave up.
y=e^x

2. Index laws with base e

e^a e^b=e^{a+b}, e^a/e^b=e^{a-b}, (e^a)^n=e^{an}. Calculator: \ln means \log_e; use shift–ln for e^x.

3. Transformation language

  • y=e^{-x} — reflect in the y-axis (decay).
  • y=e^x+c — vertical shift; asymptote moves with it.
  • y=e^{x-b} — horizontal shift; also e^{-b}e^x (vertical dilation).
  • y=Ae^x — vertical stretch; equivalently shift left by \ln A when A>0.

4. Tangents when gradient = height

For y=ke^x, y'=ke^x as well, so at a point the tangent slope equals the y-coordinate. Normals use the negative reciprocal.
