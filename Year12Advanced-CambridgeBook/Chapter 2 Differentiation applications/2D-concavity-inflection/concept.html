2D · Concavity and points of inflection

Direct path: Concept → Tutorial → Exercise → next section. No extra hubs.

What this section is about

Concavity says how the curve bends; inflection is where the bend flips.

  • Concave up (smiley): f''(x)>0 — slope rising.
  • Concave down (frown): f''(x)<0 — slope falling.
  • Inflection: concavity changes (often where f''=0 and sign changes).
  • Extra: sometimes f'' tests a stationary point (second-derivative test).

Full detail and examples live in the Tutorial · theory — this page only sets the scene.
