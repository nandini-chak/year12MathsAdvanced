5 · Exercise 2G

a Sketch the function y =  p 1 −(x + 1)2 , for −2 ≤x ≤0, p 1 −(x −1)2 , for 0 < x ≤2. (Hint: Each part is a semi-circle, which can easily be seen by squaring.) Discuss the continuity and differentiability of the function at x = 0. b Repeat part a for y =  p 1 −(x + 1)2 , for −2 ≤x ≤0, − p 1 −(x −1)2 , for 0 < x ≤2.

a For −2 ≤x ≤0, squaring gives (x + 1)2 + y2 = 1, so this part is the upper semicircle with centre (−1, 0) and radius 1. For 0 < x ≤2, squaring gives (x −1)2 + y2 = 1, so this part is the upper semicircle with centre (1, 0) and radius 1. At x = 0, both pieces meet at (0, 0). Thus lim x→0−f(x) = 0 = f(0) = lim x→0+ f(x), so f is continuous at x = 0. Differentiating each piece gives f ′(x) = − x + 1 p 1 −(x + 1)2 (x < 0), f ′(x) = − x −1 p 1 −(x −1)2 (x > 0). Hence lim x→0−f ′(x) = −∞, lim x→0+ f ′(x) = +∞. The function is therefore not differentiable at x = 0; the graph has a cusp there. b The left-hand piece is the upper semicircle with centre (−1, 0) and radius 1, while the right-hand piece is the lower semicircle with centre (1, 0) and radius 1. At x = 0, both pieces meet at (0, 0), so lim x→0−f(x) = 0 = f(0) = lim x→0+ f(x). Therefore the function is continuous at x = 0. For the two pieces, f ′(x) = − x + 1 p 1 −(x + 1)2 (x < 0), f ′(x) = x −1 p 1 −(x −1)2 (x > 0). Thus lim x→0−f ′(x) = −∞, lim x→0+ f ′(x) = −∞. There is no finite derivative at x = 0, but both sides have the same vertical direction. The function is not differentiable at x = 0 and has a vertical tangent there.
