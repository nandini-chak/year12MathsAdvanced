22 · Exercise 2A

a If f(x) = −x3 + 2x2 −5x + 3, find f ′(x). b By evaluating the discriminant ∆, show that f ′(x) < 0 for all values of x. c Hence deduce the number of solutions of the equation 3 −5x + 2x2 −x3 = 0.

a Given f(x) = −x3 + 2x2 −5x + 3 f ′(x) = −3x2 + 4x −5 b Evaluating the discriminant, we obtain: ∆= 42 −4 × (−3) × (−5) = 16 −60 = −44 (< 0) So f ′(x) has no zeroes. Further, f ′(0) = −5 (< 0), so f ′(x) is negative for all values of x, i.e. f(x) is decreasing for all values of x.
