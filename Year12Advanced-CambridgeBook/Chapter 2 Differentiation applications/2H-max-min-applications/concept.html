2H · Applications of maximisation and minimisation

Direct path: Concept → Tutorial → Exercise → next section. No extra hubs.

What this section is about

Turn a real-world question into a function, then maximise or minimise it.

  • Examples: biggest box from cardboard · least metal in a can · max profit.
  • Steps: draw → name variables → write y=f(x) → differentiate → test.
  • Domain: only use sensible values (lengths > 0, etc.).
  • Finish: answer the word question with units, not just “x=3”.

Full detail and examples live in the Tutorial · theory — this page only sets the scene.
