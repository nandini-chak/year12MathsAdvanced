Notes to copy

Write these into your book before the demonstration. They are the facts you will use on the worksheet.

1. Words

  • Function f: each input x has exactly one output f(x).
  • Graph of y=f(x): the set of points (x,f(x)).
  • Transformation: a rule that moves, stretches, compresses or flips a graph.

2. Translations (slide, same shape)

y=f(x)+c
  • c is the vertical shift. c>0 up; c<0 down.
  • Only the y-coordinate changes: (x,y)\mapsto(x,y+c).
y=f(x-b)
  • b is the horizontal shift. b>0 right; b<0 left.
  • The minus sign is the trap: y=f(x+2) is b=-2, so the graph moves left 2.

3. Dilations and reflections (change size or flip)

y=kf(x)
  • Maps (x,y)\mapsto(x,ky).
  • |k|>1 stretch vertically; 0<|k|<1 compress vertically.
  • k<0 also reflects in the x-axis.
y=f(ax)
  • Maps (x,y)\mapsto(x/a,\,y).
  • Horizontal factor is 1/|a|. So |a|>1 makes the graph narrower.
  • a<0 also reflects in the y-axis.

4. Combined form (copy this table)

y=kf\big(a(x-b)\big)+c
LetterWhere it sitsWhat it does
koutside, in front of fvertical dilation by |k|; reflect in x-axis if k<0
aattached to x insidehorizontal dilation by 1/|a|; reflect in y-axis if a<0
binside, as x-bhorizontal translation of b (positive = right)
coutside, added on the endvertical translation of c (positive = up)

Order (always): dilations and reflections first, then translations. Outside letters k,c are vertical; letters with x (a,b) are horizontal.

If the inner expression is not factored, factor it before you read b. Example: f(3x+6)=f\big(3(x+2)\big), so a=3 and b=-2, not “shift 6 left”.

5. Mapping a known point

If (x,y) is on y=f(x), its image on y=kf(a(x-b))+c is

(x,y)\mapsto\left(\dfrac{x}{a}+b,\,ky+c\right)

Check by substituting the new x-coordinate back into the transformed equation.

Three traps to underline
  • y=f(x+b) moves left, not right.
  • Stretch then shift is not the same as shift then stretch (e.g. 2x^2+4 vs 2(x^2+4)).
  • Always factor a(x-b) before naming the phase shift.

Translations

A translation slides every point the same distance. Shape and size do not change.

  • y=f(x)+c — vertical. If c>0 the graph goes up.
  • y=f(x-b) — horizontal. If b>0 the graph goes right (the minus sign is the usual trap).

A point (x,y) on the parent maps to (x+b,\,y+c).

Example 1 — replay

Parent key points (-3,-1),(-1,1),(1,1),(3,-1) mapped by (x,y)\mapsto(x+3,y+2) to sketch y=f(x-3)+2.

y=f(x) y=f(x-3)+2
Idea summary. y=f(x)+c shifts vertically by c. y=f(x-b) shifts horizontally by b.

Dilations and reflections

  • y=kf(x) maps (x,y)\to(x,ky). Stretch if |k|>1; compress if 0<|k|<1; reflect in the x-axis if k<0.
  • y=f(ax) maps (x,y)\to(x/a,\,y). Compress horizontally if |a|>1; stretch if 0<|a|<1; reflect in the y-axis if a<0.

Describe transformations

General form (do not memorise — read where each letter sits):

y = k f(a(x-b)) + c

  • k vertical dilation by |k|; reflect in x-axis if k<0
  • a horizontal dilation by 1/|a|; reflect in y-axis if a<0
  • b horizontal translation; c vertical translation

Order: dilations and reflections first, then translations. Letters outside the function (k,c) are vertical; letters with x (a,b) are horizontal.

Example 3 — \sqrt{x} to y=-3\sqrt{x-5}+1

Parameters: k=-3, b=5, c=1. Sequence: stretch by 3, reflect in the x-axis, shift 5 right, shift 1 up.

Check with (4,2) on the parent: (4,2)\to(4,-6)\to(9,-6)\to(9,-5). Then x=9 in the equation gives -3\sqrt{4}+1=-5.

y=\sqrt{x} y=-3\sqrt{x-5}+1

Order matters (exploration)

For vertical changes on f(x)=x^2, stretching then shifting is not the same as shifting then stretching.

Stretch 2, then down 4 → y=2x^2-4

Down 4, then stretch 2 → y=2(x^2-4)=2x^2-8

The lesson’s y=2(x+3)^2-4 matches stretch then translate (and a shift left of 3), not translate-then-stretch.
